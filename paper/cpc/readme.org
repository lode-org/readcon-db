#+TITLE: CPC companion (readcon-db)

readcon-db is the *companion campaign store* for the Computer Physics
Communications manuscript whose *main claim* is
[[https://github.com/lode-org/readcon-core][readcon-core]]
(CON spec v2/v3 and interchange). Do not write a second paper for
this crate alone. Deposit the core and readcon-db freeze tags
together.

The core tree already prints the two-atom NEB band
(=scripts/run_cpc_vignette.sh= + =resources/examples/neb_band.tsv=)
and, when =readcon-db= is on =PATH=, ingests that file and selects
=neb_bead= 0--3. This repository does not duplicate that vignette.

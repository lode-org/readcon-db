| API                                                          | Role                                                                                                                                                                                                         |
|--------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =ConCorpus::annotate_topology=                               | Shells =seams fingerprint FILE --format json --cutoff C --graph G --hops H=. Resolves the binary from =--seams= / =SEAMS= / =PATH=. Default graph =cutoff=, hops 2. Cutoff required. Refuses a mixed method. |
| =ConCorpus::find_by_topology_path= / =find_by_topology_text= | Fingerprint a file (or CON text) with the recorded corpus params and look up =idx_topo=. Errors if nothing is annotated or if seams is missing.                                                              |
| =Select::topo_key=                                           | Prefix-scan =idx_topo= (topology-key utf-8 || =0xff= || =FrameKey=).                                                                                                                                         |
| =TrajMeta=                                                   | Optional =topo_cutoff=, =topo_graph=, =topo_hops=, =topo_method= (serde default; old JSON still loads). Ingest/extend preserve these fields.                                                                 |

=set_trajectory_units= converts stored numbers. A v3.1 clock or velocities frame with no =units.time= is an error, not a silent =fs=; v1, v2, and v3.0 clocks with no =units.time= still convert as =fs=. =append_trajectory_path_units= and =extend_trajectory_path_units= stamp incoming frames. H5MD velocities follow D10 and are written as =Angstrom ps-1=. v1, v2, and v3.0 frames use =(amu*angstrom^2/eV)^0.5= whatever the time label says. v3.1 frames use =units.time= and =collect_h5md= fails when velocities have no =units.time=. =H5mdCollectOpts.velocity_time_unit= overrides that rule for a file that breaks it. The clock (=time=, =timestep=, H5MD time) uses =units.time= when that key is present. A v3.1 frame with =time= or =timestep= and no =units.time= is an error, and the same override supplies that missing clock unit. A present =units.time= still scales the clock. v1, v2, and v3.0 clocks with no =units.time= are read as =fs=.

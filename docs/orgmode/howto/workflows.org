** MPI: one rank packs, the rest receive
:PROPERTIES:
:CUSTOM_ID: mpi-one-rank-packs-the-rest-receive
:END:
When every rank needs the *same* frame, do not open LMDB on every rank. Rank 0 of the communicator the host already owns (=lmp->world=, an mpi4py =Comm=, a Fortran INTEGER handle) packs RCSO; =MPI_Bcast= on *that* handle; workers unpack with no corpus. The library does not call =MPI_Init= and does not name the process-wide world communicator.

#+begin_src C
#include "readcon-db-mpi.h"
rkrdb_bcast_packed_frame(lmp->world, 0, dir, traj, frame, &buf, &n);
rkrdb_bcast_packed_frames(lmp->world, 0, dir, trajs, frames, nkeys, &buf, &n);
#+end_src

#+begin_src python
from readcon_db import bcast_packed_frame, bcast_packed_frames
blob = bcast_packed_frame(lmp.world, dir, traj, frame)  # mpi4py Comm
batch = bcast_packed_frames(lmp.world, dir, [(traj, 0), (traj, 1)])
#+end_src

The other legal path: every rank =open_readonly= (shared mmap) when ranks touch *different* keys.

Many frames on one collective: =rkrdb_bcast_packed_frames= / Python =bcast_packed_frames= (RCSB envelope). Grain is a NEB band or dump window, not one EndStep per image.

Node-local ingest, then drain to the PFS (Frontier =/mnt/bb=, Aurora =/tmp=): one writer per shard id, or unique dest per node when shard ids overlap, then =join-drained=. Full sequence, refuses, and C/Fortran shard-directory opens: @@rst::doc:`/howto/campaign`@@.

#+begin_src sh
readcon-db shard-init /mnt/bb/$USER/campaign --shards 64
readcon-db shard-ingest /mnt/bb/$USER/campaign --shard $S --start-id $T \
    --units '{"length":"angstrom","energy":"eV","time":"fs"}' run.con
# ranks close
# One writer per shard id can drain to a shared dest.
# Overlapping shard ids (more writers than shards): unique dest per node, then join-drained.
readcon-db drain /mnt/bb/$USER/campaign /lustre/orion/proj/campaign/node_$SLURM_NODEID
readcon-db join-drained /lustre/orion/proj/campaign_single \
    /lustre/orion/proj/campaign/node_*
#+end_src

** H5MD interchange
:PROPERTIES:
:CUSTOM_ID: h5md-interchange
:END:
Cooked =[T][N][3]= export (CON stays authority in the corpus):

#+begin_src python
from readcon_db import ConCorpus
db = ConCorpus("/lustre/orion/proj/campaign_single", readonly=True)
db.export_h5md(traj_id=1, path="traj.h5")
#+end_src

Dest must not exist (=File= ="x"=). A write failure removes the dest.

Time on the file is dest =ps=: CON =header.time()=, or =i * timestep=, else the frame index. A v3.1 frame with =time= or =timestep= and no =units.time= is an error. =velocity_time_unit= supplies that missing clock unit and overrides the D10 velocity rule for a file that breaks it. A present =units.time= still scales the clock. v1, v2, and v3.0 clocks with no =units.time= are read as =fs=. Optional force and velocity groups are dest =kJ mol-1 Angstrom-1= and =Angstrom ps-1=. Velocities follow D10: v1, v2, and v3.0 use =(amu*angstrom^2/eV)^0.5= whatever the label says; v3.1 uses =units.time= and fails if that key is missing. =readcon-db compact-join= is the single-root join (=open_existing=).

** XYZ and other formats
:PROPERTIES:
:CUSTOM_ID: xyz-and-other-formats
:END:
Use *readcon-core chemfiles ingress* (=read_chemfiles=, =read_chemfiles_nth=, Rust/C =rkr_read_chemfiles*=) to obtain =ConFrame=s, write CON if needed, then ingest. Chemfiles converts format units on read (GRO nm → Å) and stamps line-2 =units= as Å / ps / amu; use =skip= / =step= / =read_step= rather than loading every frame. ** Fair ASE sqlite comparison
:PROPERTIES:
:CUSTOM_ID: fair-ase-sqlite-comparison
:END:
Use *=examples/benchmarks/fair_ase_protocol.py=*. The protocol write-up is =examples/benchmarks/FAIRNESS.md=. Raw lines and the type-7 table are =examples/benchmarks/results/fair/=.

Both stores receive the same records: symbols, positions, cell, periodicity, masses, forces, energy, and =frame_index=. ASE is SQLite, =journal_mode=DELETE=, =synchronous=FULL=. Each insert is one transaction and one commit fsync, on a database file created for that sample. One warmup is discarded. Six serial samples alternate the two tools. The summary is the Hyndman–Fan type-7 median and IQR. A field mismatch aborts the run.

A cold read calls =posix_fadvise(DONTNEED)= on the closed database files, then times a readonly open plus the read. =/proc/sys/vm/drop_caches= was not writable on the measurement host, so it was not used. A warm read is the next read on the already open store. The timed close does not call =gc.collect()=. Full reads use =read_columns=. The single-frame query is =frame_index= of the middle frame.

=open= prefetches a corpus under 1 MiB with one =pread= before it maps the environment. Selected cold is the query after that prefetching open. =cold-open= is the end-to-end number: the cache drop stays outside the clock, and the clock is the open plus the query. The harness does not read the file.

The published CPC ingest (=paper/cpc/logs/db.log=, 40 frames of 8 Cu, no warmup) is readcon-db 4.67 ms and ASE 72.3 ms. ASE committed once per frame. The fair rerun of that insert, one commit each, is readcon-db 1.70 ms and ASE 5.17 ms.

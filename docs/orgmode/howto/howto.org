Same job in every language: open a corpus, ingest a =.con=, select, read a hash.

** Rust
:PROPERTIES:
:CUSTOM_ID: rust
:END:
#+begin_src rust
use readcon_db::{ConCorpus, Select};

let db = ConCorpus::open("/tmp/corpus")?;
db.append_trajectory_path(1, "run.con")?;
let keys = db.select(
    &Select::new()
        .trajectory(1)
        .require_symbol("Cu")
        .natoms_range(1, 10_000)
        .limit(100),
)?;
let h = db.frame_hash(keys[0])?;
let frame = db.get_frame(keys[0])?;
#+end_src

Exact match: =Select::new().exact_hash(h.to_bytes())=.

** Python
:PROPERTIES:
:CUSTOM_ID: python
:END:
#+begin_src python
import readcon_db

db = readcon_db.ConCorpus.open("/tmp/corpus")
db.append_trajectory_path(1, "run.con")
sel = readcon_db.Select().require_symbol("Cu")
keys = db.select(sel)
h = db.frame_hash(keys[0])
text = db.get_frame_text(keys[0])
#+end_src

=maturin develop --features python= from a checkout. Module name is =readcon_db=.

** C / C++
:PROPERTIES:
:CUSTOM_ID: c-c
:END:
#+begin_src C
#include "readcon-db.h"

RkrdbCorpus *db = rkrdb_open("/tmp/corpus");
rkrdb_append_trajectory_path(db, 1, "run.con");
/* Select via rkrdb_select_* / rkrdb_select_meta; see api_c */
rkrdb_close(db);
#+end_src

C++ RAII: =readcon_db::Corpus=. MPI pack/bcast takes the *caller* communicator (=readcon-db-mpi.h=). The library does not call =MPI_Init=. Details: @@rst::doc:`/reference/c`@@.

** Fortran
:PROPERTIES:
:CUSTOM_ID: fortran
:END:
=fortran/ReadConDb= is =bind(C)= over the same =rkrdb_*= ABI. Build with =pkg-config --cflags --libs readcon-db= after a prefix install, or the clib tarball. Details: @@rst::doc:`/reference/fortran`@@.

** Many writers
:PROPERTIES:
:CUSTOM_ID: many-writers
:END:
Do not open one LMDB env from two writers. Partition with @@rst::doc:`/howto/campaign`@@ (=shard-init=, =shard-ingest=, =drain=, =join-drained=).

:CUSTOM_ID: units-and-h5md

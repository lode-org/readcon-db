** Install
:PROPERTIES:
:CUSTOM_ID: install
:END:
Pick *one* language. Pins match this tree (=0.1.8=). Core is =readcon-core= 0.16.2 (pulled automatically for Rust).

| Package        | Install                                                     | Destination                                                    |
|----------------+-------------------------------------------------------------+----------------------------------------------------------------|
| Rust           | =cargo add readcon-db=                                      | this site · [[https://crates.io/crates/readcon-db][crates.io]] |
| CLI            | =cargo install readcon-db --locked=                         | =readcon-db= binary                                            |
| Python         | =pip install readcon-db=                                    | [[https://pypi.org/project/readcon-db/][PyPI]]                 |
| C / C++        | CMake FetchContent, Meson wrap, or =pkg-config readcon-db=  | @@rst::doc:`/howto/install`@@                                         |
| Fortran        | =fortran/ReadConDb= after a prefix or clib install          | @@rst::doc:`/reference/fortran`@@                                     |
| Prebuilt C ABI | =readcon-db-clib-$VER-$target.tar.gz= on the GitHub Release | @@rst::doc:`/howto/install`@@                                         |

CON parse/write outside the corpus API is [[https://lode-org.github.io/readcon-core/getting-started.html][readcon-core]] (=pip install readcon= / =cargo add readcon-core=).

** Smoke test
:PROPERTIES:
:CUSTOM_ID: smoke-test
:END:
From a checkout (fixture under =resources/test/=):

#+begin_src python
import tempfile
from pathlib import Path
import readcon_db

root = Path(tempfile.mkdtemp())
db = readcon_db.ConCorpus.open(str(root))
db.append_trajectory_path(1, "resources/test/tiny_cuh2.con")
keys = db.select(readcon_db.Select().require_symbol("Cu"))
print(len(keys), db.frame_hash(keys[0]))
#+end_src

#+begin_src rust
use readcon_db::{ConCorpus, Select};
let db = ConCorpus::open("/tmp/readcon-db-smoke")?;
db.append_trajectory_path(1, "resources/test/tiny_cuh2.con")?;
let keys = db.select(&Select::new().require_symbol("Cu"))?;
println!("{} {:?}", keys.len(), db.frame_hash(keys[0])?);
#+end_src

** Scope
:PROPERTIES:
:CUSTOM_ID: scope
:END:
| Task                             | Path                                                       |
|----------------------------------+------------------------------------------------------------|
| Parse or write one =.con=        | [[https://lode-org.github.io/readcon-core/][readcon-core]] |
| Many frames, filter, hash        | =readcon-db=                                               |
| Field meanings (energy, formula) | =readcon_core::index_proj= (same keys as db indexes)       |
| Foreign XYZ / PDB / GRO          | core chemfiles path, then ingest CON                       |

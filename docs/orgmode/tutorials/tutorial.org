This walk-through opens an empty corpus directory, ingest the in-repo CuH2 fixture, selects copper-containing frames, and prints a content hash. Use a throwaway directory.

** Open
:PROPERTIES:
:CUSTOM_ID: open
:END:
#+begin_src python
from pathlib import Path
import tempfile
import readcon_db

root = Path(tempfile.mkdtemp())
db = readcon_db.ConCorpus.open(str(root))
#+end_src

#+begin_src rust
use readcon_db::{ConCorpus, Select};
let db = ConCorpus::open("/tmp/readcon-db-tutorial")?;
#+end_src

=open= creates the LMDB environment if the directory is new. One writer at a time; many readers may mmap the same tree.

** Ingest
:PROPERTIES:
:CUSTOM_ID: ingest
:END:
#+begin_src python
db.append_trajectory_path(1, "resources/test/tiny_cuh2.con")
#+end_src

#+begin_src rust
db.append_trajectory_path(1, "resources/test/tiny_cuh2.con")?;
#+end_src

The blob on disk is CON text. =traj_id= =1= is yours to assign; later appends to the same id extend that trajectory.

** Select and hash
:PROPERTIES:
:CUSTOM_ID: select-and-hash
:END:
#+begin_src python
keys = db.select(readcon_db.Select().require_symbol("Cu"))
h = db.frame_hash(keys[0])
print(len(keys), h)
text = db.get_frame_text(keys[0])
#+end_src

#+begin_src rust
let keys = db.select(&Select::new().require_symbol("Cu"))?;
let h = db.frame_hash(keys[0])?;
let text = db.get_frame_text(keys[0])?;
assert_eq!(db.find_by_hash(h)?, Some(keys[0]));
#+end_src

=Select= is an explicit filter (symbol, atom count, energy, section flags, exact hash). It is not SQL. Hits are keys; decode a key when you need a =ConFrame= or the raw CON blob.

** What you just did
:PROPERTIES:
:CUSTOM_ID: what-you-just-did
:END:
1. Created a corpus directory (mmap LMDB).
2. Stored a CON fixture under ~traj_id = 1~.
3. Filtered without loading every atom of a large tree.
